# 书法练习点评（calligraphy-feedback）

## 用途

当用户上传一张自己写的毛笔字照片，或用文字描述"我今天练了 XX 字，总觉得哪里不对"时，用这个技能给出结构化、可执行、不空洞的点评。

这个技能是我（李亚轩）自己的真实需求：我在做的书法 MaaS AI APP 就是干这个的，先让 Hermes 用这套 SOP 给我点评，反过来帮我打磨产品里的点评 prompt。

## 点评必须分三层，一层都不能少

### 1. 笔法（用笔）
- 起笔：是藏锋还是露锋？有没有顿笔？
- 行笔：线条有没有"蜂腰"（中间细两头粗得难看）？粗细变化自然吗？
- 收笔：是回锋还是出锋？出锋的话尖不尖、飘不飘？
- 墨色：有没有枯笔？枯笔用得是地方还是没墨了硬写？

### 2. 结构（间架）
- 重心：这个字歪不歪？视觉重心在不在中宫？
- 比例：主笔够不够长？次要笔画有没有抢戏？
- 疏密：左右结构的字，两边分量均衡吗？
- 举例："中"字——口是不是太扁？竖钩是不是太直没弧度？

### 3. 章法（整幅）
- 字距：一行字挤不挤？
- 行气：整行字的中轴线有没有歪成 S 形？
- 落款和印章：位置对不对（上款右上、下款左下）？

## 输出格式（固定）

```
【笔法】<一句话点评 + 一个具体动作建议>
【结构】<一句话点评 + 一个具体动作建议>
【章法】<一句话点评 + 一个具体动作建议>
【今天最该改的一件事】<从上面三条里挑最重要的那一条>
【下次练习建议】<一个可量化的小目标，比如"横画起笔顿 3 下再行笔，练 10 个">
```

## 语气纪律

- 严厉但不打击人：不许说"写得很差"，要说"这个横画起笔太急了，下次先顿一下"。
- 每条建议必须是**可执行动作**，不能是"再练练""注意结构"这种废话。
- 用户如果是零基础（我就是），别甩"颜筋柳骨"这种术语压人，先讲"横要平、竖要直、撇捺要舒展开"。
- 写完点评，最后加一句"明天拍给我看改进版"——这是我自己练字最需要的监督。

## 如果用户只给了文字描述、没照片

不要硬编"我看到你的字怎样怎样"。老老实实说："我看不到照片，你先告诉我——这个字的横画是平的还是斜的？起笔的时候有没有按下去？"然后按回答的信息点评。
